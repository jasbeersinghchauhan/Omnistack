# OmniStock Backend

A RESTful backend API for **OmniStock**, a **Hyperlocal Product Discovery System** that enables users to discover products available in nearby local stores.

## Tech Stack

- Node.js
- Express.js
- PostgreSQL
- Passport JWT
- JSON Web Token (JWT)
- bcrypt
- dotenv

## Installation

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
DATABASE_URL=<your_database_url>
JWT_SECRET=<your_jwt_secret>
PORT=3000
```

Start the server:

```bash
npm start
```
